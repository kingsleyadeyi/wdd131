About BOM Journey

BOM Journey is an interactive website designed to encourage meaningful and consistent study of the Book of Mormon.

Project Purpose

BOM Journey helps individuals develop regular scripture study habits through personal goals, chapter tracking, and an interactive scripture reading experience.

The website combines HTML, CSS, and JavaScript to provide an engaging learning experience while demonstrating modern web development techniques.

Features include a digital passport, an interactive Book of Mormon scripture reader, automatic chapter progress tracking using localStorage, responsive design, and dynamic JavaScript functionality.
